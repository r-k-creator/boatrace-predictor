# 支払い停止期間(2026-10-01〜10-10)の後追い再現・記録

学習データとして保存するだけで、本番ロジック・しきい値には一切反映していない。
生成: `scripts/analysis/backtest_suspension_period.py`(確定オッズは `scripts/tools/backfill_odds.py` で取得、
`data/archive/analysis_outputs/odds_backfill_suspension_20261001_20261010.csv`)。

## 背景
候補選定Routine(Claude依存)が10-02から停止し、候補・買い目・締切メール・結果評価・日次メールが止まった。
10-01は候補9件あったが、24場12Rなど結果未確定のため夜の評価がスキップされた(別原因)。再学習・結果取得は毎晩動いていた。

## 前提と限界
- **実際の候補選定は再現できない**。そのため結果確定済みの全レース(1,536R)を母集団にした代理で再現している。
- オッズは**レース確定後の確定オッズ**(締切前とは値が異なりうる)。
- 結果欠測84レース(順延・中止ではなくすべて取得漏れ)は boatrace.jp から補完済み。`results_entries.csv`(艇別)は補完していない。

## 読み取りの注意(観察のみ)
全レースにEVティアを適用すると、EV>=2.0に該当するレースが約57%(874/1,536)と多く、回収率も62.6%と、
60日バックテスト(実際に買ったレース母集団、回収率140.9%)とは大きく食い違う。母集団が違う(候補に絞らない)
うえ、的中が27件と少なくぶれが大きいため、EVティアの優劣の結論には使えない。
EVティアを候補レースに限定する現行の設計意図を裏付ける参考データと位置づける。
